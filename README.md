## Gaps

I have multiple voices (Rings, Plaits, Saich), but very few sound shaping modules. I could use a multipurpose waveshaper, wavefolder, delay, reverb, etc.

- Mutable Warps

Marbles, OCHD, and Tides are great, but I'm lacking a general-purpose function generator.

- Make Noise Maths
- Pam's New Workout

I'm a bit short on utilities, particularly for attenuating, attenuverting, mixing, and offsetting CVs. Veils is great, but it leans quite far towards VCA and less towards utility.

- Mutable Blinds
- 3x MIA
- Instruo 1f?
- Instruo Carn?

If I'm removing the Neutron from my rack, I'll also need some other generic utilities - mults, buffered mults, etc.
